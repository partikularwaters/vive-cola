# VIVE Brand Deck Assets and Vector Shapes

This directory contains extracted source images from the original 8-page brand deck (`source/VIVE! - Cola Brand.pdf`), alongside generated vector SVG and 1024×1024 high-resolution transparent PNG shape assets.

All generated shapes adhere strictly to the approved palette in [brand-spec.md](../../brand-spec.md).

## Quick Links
- **Interactive Visual Gallery:** Open [showcase.html](showcase.html) in any browser to preview and download all assets.
- **High-Resolution Contact Sheet:** [brand-assets-contact-sheet.png](brand-assets-contact-sheet.png) (1440×2400 overview render).
- **Web Production Mirror:** All 70 SVG and PNG shape assets are mirrored in `assets/shapes/` for direct consumption by website pages.

## Approved Color Palette

| Color Name | Hex Code | Purpose in Shapes |
|---|---|---|
| Sun Yellow | `#F4BD6A` | Signature 10-point stars, accent triangles, and energetic highlights |
| VIVE Orange | `#F27A21` | Core brand color, solid bursts, and acute triangles |
| VIVE Navy | `#2B3990` | Structural headers, contrasting badges, and deep accent shapes |
| Brand Off-White | `#F9F9F9` | High-contrast overlays and wireframe strokes |
| Deep Navy / Ink | `#1D2766` | Secondary contrast grounds, shadow particles, and dark accents |
| Cream | `#E4CEAF` | Decaffeinated flavor ground variants |
| Solid Black | `#111111` | Extra Caffeine flavor ground variants |

## Generator Tooling

To regenerate or modify any shapes, run the automated generator script:
```bash
python3 scripts/generate_deck_assets.py
python3 scripts/build_shape_showcase.py
```
This script rebuilds all SVGs, supersampled PNGs, and the interactive HTML showcase simultaneously.
