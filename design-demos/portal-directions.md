# VIVE Web Portal Poster: Three Simple Directions (2026-11-18)

Brief (client's words):
> Let's change the "Official Digital Router" to "Official Web Portal"
> Remove the stores, no logos, no store names.
> website should be one-line.
> Three bottles should be the dominant.

Each direction keeps four elements only: the V!VE wordmark, the "Official Web Portal" tag, the three cans (Glow, Classic, and Focus), and the URL `vive-cola.vercel.app` on one line with a short "Tap anywhere to visit" hint. The whole page links to the site. All brand shapes are SVG images, because WeasyPrint ignores CSS `clip-path`.
